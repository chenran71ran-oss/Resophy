# AGENTS.md

Preserve upstream licenses, attribution, user changes and existing functionality.
Keep modifications inside this source repository. The integration uses Paperless
as the document/permission authority and an independent research service.
Never commit credentials, databases, documents, annotations, logs or backups.
Tests use isolated data and services. Model processing must be explicitly
submitted per paper; never trigger paid jobs from browsing or automatically
retry interrupted work. Reuse saved results with matching provenance/options.
Verify permissions on every read/write/download, including revoked access.
Record actual tests separately from mocks, real AI and production validation.
Production changes require the owner's scoped authorization and capacity,
consistent backup, restore and rollback checks. Never clean the whole server,
delete production volumes or change unrelated/shared infrastructure.
